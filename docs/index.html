Features

What it does

Built with React, TypeScript, and Electron, AudioViz Pro pairs local file playback and live microphone input with 10 visualizer effects — 6 Canvas 2D and 4 WebGL (Three.js) — that switch seamlessly at runtime. More than 20 adjustable parameters and a preset system with 7 built-ins cover color themes, speed, sensitivity, and FFT size, while WebM video (with audio via FFmpeg), animated GIFs, and one-click PNG screenshots make the results easy to share. The bilingual English/Chinese UI comes with global keyboard shortcuts.

Video / GIF / screenshot export

Keyboard controls for playback, visualizer switching, color themes, mirror mode, fullscreen, and capture.

Quick Start

Quick start

  1. npm install to set up dependencies.
  2. npm run dev for the browser dev server, or npm run dev:electron for Electron dev mode.
  3. Drop in an audio file or enable the microphone to start visualizing.
  4. Press A / D to switch visualizers, S to screenshot, F for fullscreen.
shell
npm install

npm run dev           # browser dev server
npm run dev:electron  # Electron dev mode

npm run build         # production build
npm run build:electron # Electron desktop app

项目简介

AudioViz Pro 基于 React、TypeScript 与 Electron 构建，将本地文件播放与麦克风实时输入接入 10 种可视化效果——6 种 Canvas 2D 与 4 种 WebGL (Three.js)——并可在运行时无缝切换。20+ 项可调参数与内置 7 个预设的预设系统覆盖颜色主题、速度、灵敏度与 FFT 大小；WebM 视频（含音频，通过 FFmpeg 编码）、动画 GIF 与一键 PNG 截图让成果便于分享。双语（英文/中文）界面配备全局键盘快捷键。

🎙️

音频输入

本地文件上传（拖拽或点击）+ 麦克风实时输入。

10 种可视化效果

6 种 Canvas 2D 与 4 种 WebGL (Three.js) 效果，运行时无缝切换——从频率条形图、极光带到粒子风暴与 DNA 螺旋。

高度定制

20+ 项可调参数：颜色主题、速度、灵敏度、FFT 大小与特效参数。
